# To-Do List Project

## Description
A simple command-line To-Do List application that allows users to add, remove, view, and save tasks. Tasks are stored in a file for persistence.

## Features
- Add new tasks
- Remove tasks
- View the list of tasks
- Save tasks to a file
- Load tasks from a file

## How to Run
1. Run `todo_list.py`
2. Follow the on-screen menu to manage tasks.

## Requirements
- No external libraries required.
- Works with Python 3+
